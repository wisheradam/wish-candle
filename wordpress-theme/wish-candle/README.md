# Wish Candle WordPress theme

Custom classic WordPress theme matching the current Wish Candle storefront.

## Included

- Responsive header, navigation, homepage sections and footer
- WooCommerce product grids, catalog, cart count and product pages
- Customizer fields for announcement, phone, email, address and social links
- WordPress menus and custom logo support
- CDN-backed design imagery while the staging site is built

## Installation

1. Install and activate WooCommerce.
2. Upload `wish-candle.zip` in Appearance → Themes → Add New → Upload Theme.
3. Activate **Wish Candle**.
4. Assign the Primary, Footer shop and Footer support menus.
5. Set the homepage to a static page and configure store details in Appearance → Customize.

The production cutover should happen only after products, checkout, payment, delivery and legal pages have been tested.
